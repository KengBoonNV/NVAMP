Import an NVAMP backup

Choose an nvamp-backup-YYYY-MM-DD.json file (from Team & settings → Back up all data). Records are added or replaced by id; nothing is deleted. Only NVAMP owners can import. Photos, signatures and documents are not inside the backup and won't appear.
